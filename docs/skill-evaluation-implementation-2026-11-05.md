# スキル小事例評価基盤の実装記録

作成日：2026-11-05 JST。参照設計：SKILL-EVAL-PORTABLE-1.0（Open Estimateの横展開設計）。操作方法は[評価README](../evaluation/skill/README.md)。

## 実装

- `evaluation/skill/core/`へ固定コピー、inventory、hash、予算、実行状態、証拠検証、意味レビュー取込み、追記型再採点、条件比較を追加。
- Codex CLI用ホストを追加。本文供給、新規セッション、ユーザー設定を無視する起動設定、読取り専用、外部接続無効設定、時間制限、使い捨てプロセスでの停止確認を使用。実モデル・実ロード・強い隔離の未観測を明示。
- 補助金相談・企業調査の4合成ケースをProject adapterへ分離。coreに業務の正解を置かない。第二の回答形式を使う固定テストで境界を検証。
- plan、run、show、review-template、regrade、compare、recover、メタデータのみのredacted exportを追加。run以外はモデルを起動しない。
- スキル配下の既存配布ZIPを候補から明示除外。本文供給へ予期しないバイナリが入ると起動前に拒否。
- 固定テストと全件planだけを動かすGitHub Actionsを追加。実モデル評価を自動起動しない。
- 既存の製品配布allowlistと製品ソースが評価コードを参照しないことを検査。製品スキル・サーバー・公開設定は編集していない。

## 検証と制約

レビューで判明した2件を修正した。履歴とは別の`assessment-head.json`に件数・最新セットID・最新hashを保存し、末尾1件・複数件の削除を読込み時に拒否する。書込みは排他し、履歴保存→headの原子的更新の順とする。headの欠落や不整合は自動修復しない。headのない旧記録は再認定しない。

同一実行の比較は初回→最新とし、左右のassessment IDの明示指定も追加した。CLI経由でPASS→FAIL、異なる採点ID、regression=true、保存された比較結果を確認した。モデルは起動していない。修正後の評価基盤テスト40件、既存テスト130件、型チェック、`plan --case C001`がすべて成功した。

評価器の固定テスト、使い捨て親子プロセスの停止確認、既存130件のテスト、型チェックを実施。疑似ホストの回答やレビューはテスト専用で、スキル品質の測定結果ではない。

実モデルの基準候補／変更候補比較、実モデルでの接続・イベント形式、ネイティブなスキル選択、探索、実MCP、成果物の保存・表示、正式配布の照合・受入は未実施。最初の実モデル試験にはモデルIDと実行予算を明示する。モデル自身の申告をホスト観測へ転記しない。

設計P0〜P2の開発反復経路と、P3向けのadapter境界を実装した段階。別製品の実モデルでの横展開受入と、代表案件・正式配布をつなぐP4の実運用は未完了。release bridgeの専用自動化は設けず、候補inventory・run・assessmentと既存配布物を手順に従って照合する。

共有exportは自由記述を除いたメタデータJSONだけに限定し、生ログをマスキングした完全な証拠アーカイブの生成には対応しない。証拠の暗号署名、強い読取り隔離、利用金額の上限保証、保管期限に応じた自動削除は実装していない。これらの保証を合格記録へ後付けしない。
