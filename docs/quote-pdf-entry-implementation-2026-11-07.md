# 見積PDFを入口とする申請準備・利用開始案内

2026-11-07。プラグインのスキル、共通ページひな型、固定入力評価を更新した。公開版・インストール済み版への反映、OpenAIへの更新申請は行っていない。

## 利用者に見える変更

- 導入見積のある補助金申請準備は、会社名の質問より見積の読取りを先に行う。宛名・購入先候補・製品・数量・期間・税・費用をまとめて確認し、不足する情報だけを質問する。見積なし・添付不可でも質問から進められる。
- 1ページ目の見積と2ページ目等の共通案内を区別する。複数ページの明細や普通の1ページ見積にも対応する。共通案内の標準プランや年度で、案件の人数・金額・申請年度を上書きしない。
- 利用可能・未導入・利用可否不明を区別する。利用可能なら見積確認へ進む。ホストが対応していれば正確な検索結果から追加候補を提示し、対応しない場合は確認済みの公開ページをリンクで案内する。導入辞退・公開先不明でも一般準備を続ける。
- 販売会社向けに、利用者への開始案内とAIが参照する共通情報をまとめた別紙ひな型を追加した。顧客別の宛名や金額を重複記載しない。リンクとQRは同じ公開URLへ向け、スマホでも本人が同じPDFを添付する手順とする。
- 引継ぎメモだけを別チャットへコピーしても続けられるよう、確定事項・未確認事項・次の操作・保存未実行の説明を同じコピー範囲に含める。

PDFに記載された指示を、追加・接続・認証・同意・外部送信の許可とは扱わない。申請を頼まれていない単純な見積要約で、プラグイン導入や申請ウィザードを開始しない。
