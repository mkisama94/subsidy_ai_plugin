## 実装

申請準備スキルから `references/financial-documents.md` を、会社確定後の財務準備・決算書・添付困難の相談時に読み込む。販売会社手順からも同じ参照先へ接続した。公開API取得は既存の `get_company_activities` の `finance` を利用し、本人ログイン型の接続や新しいMCPツール、財務の自動確定処理は追加していない。

受領済みの書類と有効な公開情報は再利用し、公開照会待ちでPDF読取りを止めない。API成功・項目空欄・掲載なし・通信失敗を区別する。数値の対象法人・期間・単体/連結・単位・科目を確認し、申請候補の確認と正式添付を別管理にした。APIデータがそろっても提出書類を省略しない。

添付できないときは、既知の理由を再質問せず、紙の写真/スキャン、会計ソフトの出力、経理/税理士への依頼文、操作案内、少数項目の貼付け/手入力、手元での本人確認へ分岐する。手入力から公式決算書を作成せず、試算表を確定決算へ読み替えない。取寄せ待ちには見積や会社情報の整理を具体的に案内する。

制度根拠は同日の確認済み2026年通常枠公募要領21ページ等を参照資料に記載。他年度・他枠へ無条件に適用しない。
