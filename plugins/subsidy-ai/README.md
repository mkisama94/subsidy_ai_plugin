# 補助金AI

Jグランツの最新公開データと公募要領を参照し、日本の補助金について根拠付きで回答するためのプラグインです。

Jグランツ、国税庁法人番号システム、経済産業省の法人情報データベース（gBizINFO）、EDINETの公開情報を扱うMCPサーバーを実装しています。現在公開している15ツールと利用上の注意は以下のとおりです。

## 現在利用できるMCPツール

- `search_corporate_identities`: 国税庁の法人名検索で正式名称・法人番号・所在地・閉鎖情報を取得。複数候補は自動決定しない
- `get_corporate_identity`: 指定された法人番号について国税庁の最新公表情報を照会。閉鎖情報なしを営業実態や申請資格の保証としない
- `search_companies`: 経済産業省の法人情報データベースで法人名・所在地から法人候補を検索。複数候補は自動決定しない
- `get_company_profile`: 同データベースから法人基本情報を取得。活動情報は0件と断定せず未取得として表示
- `get_company_activities`: 同データベースの公開情報から認定、表彰、事業所、財務、特許、調達、補助金、職場情報を取得
- `verify_corporate_relationship`: 利用者が申告した親会社候補をEDINETの有価証券報告書で検証し、みなし大企業規定の確認を促す
- `assess_deemed_large_enterprise_eligibility`: 候補制度の公式要件と確認済み資本関係を照合し、対象外・申請可能性・追加確認を分ける
- `prepare_professional_consultation`: 未確認論点を、専門家への質問・準備資料・相談期限を含む引き継ぎメモに整理
- `record_official_selection_statistics`: 公的資料の申請件数・採択件数を根拠付きで保存し、比較可能な場合だけ公式採択率を計算
- `get_official_selection_statistics`: JグランツIDから保存済みの公式採択実績と出典を参照
- `estimate_program_selection_outlook`: 過去最大3回の公式実績から制度全体の参考範囲をルール算定
- `evaluate_subsidy_fit_for_company`: 経済産業省の公開法人情報と利用者が確認した補完情報をJグランツの補助金条件と照合し、値の出典と矛盾を表示
- `search_subsidies`: Jグランツ公開APIから補助金候補を検索
- `get_subsidy_detail`: Jグランツ詳細API V2から公募回、詳細、文書メタデータを取得
- `evaluate_subsidy_fit`: 補助金詳細と企業プロフィールを照合し、一致、不一致、未確認事項を分離

`search_subsidies` で都道府県を指定した場合は、その地域固有の制度と全国対象制度を統合して返します。検索結果だけで対象可否を断定せず、候補選定後に `get_subsidy_detail` と最新の公募要領を確認してください。

`evaluate_subsidy_fit` は受給資格や採択を断定しません。所在地、業種、従業員数など、Jグランツの構造化項目で確認できる範囲だけを機械的に照合し、公募要領で確認すべき事項を別に返します。企業プロフィールと補完入力は保存しません。経済産業省の法人情報データベース連携にはCloudflare Secretの `GBIZINFO_API_TOKEN` が必要です。Swagger掲載の動作確認用トークンはアプリへ設定せず、正式発行されたトークンだけを使用してください。

評価結果の英語コードはシステム連携用です。利用者への回答では `statusLabel` と `summary` を用い、「申請条件の追加確認が必要です」などの自然な日本語で説明します。保存状態やデータベース内部IDは、利用者から求められない限り表示しません。

未確認事項がある場合は、`professionalConsultation` または `prepare_professional_consultation` を使い、相談先、相談理由、具体的な質問、準備資料、相談期限を利用者向けに整理します。社会保険労務士などの顧問専門家を一次窓口とし、論点に応じて税理士・公認会計士・中小企業診断士・実施機関へ振り分けます。AIは助言と準備を担い、申請者と人間の専門家が最終判断と責任を担います。株主名簿、決算書、賃金台帳など非公開資料の内容は入力・保存しません。

法人名検索で `mayHaveMore: true` の場合、返却結果は先頭ページであり網羅的とは限りません。`statusAvailability: not_provided` は「登記中」を意味しないため、状態情報なしとして扱います。所在地の簡略入力と詳細住所は `compatible` として区別し、行政区域が同じという理由だけで完全一致とは扱いません。

EDINET連携は親会社をゼロから推測するためのものではありません。利用者に親会社候補を確認したうえで `verify_corporate_relationship` を使用します。確認した提出書類に対象会社名がない場合も、資本関係がないとは断定しません。EDINET連携にはCloudflare Secretの `EDINET_API_KEY` が必要です。全国の企業関係データは保存せず、検証時に公式の最新版を照会します。 対象会社の行に属する比率だけを抽出し、重要な根拠を最大2件に限定して返します。

EDINETで確認した資本関係と、補助金制度上のみなし大企業の扱いは別の判断です。100%子会社という事実だけで全制度から除外せず、`assess_deemed_large_enterprise_eligibility` に最新の公募要領または公式FAQの基準を渡して照合します。課税所得や役員兼務など公開情報で確認できない事項は推定せず、利用者または実施機関への確認事項として返します。この入力と判定結果は保存しません。

採択実績は、同じ公募回・同じ対象範囲の申請件数と採択件数を公式資料で確認できる場合だけ、`record_official_selection_statistics` がコードで割り算します。採択者一覧しかない場合、年度・枠・審査段階が混在する場合、民間の二次情報しかない場合は公式採択率を算定しません。保存前にWorkerが公的機関ドメインの公式HTML・テキスト・JSONを取得し、根拠文が実在することを確認します。PDFは現段階では自動照合せず保存しません。見通しは制度全体の参考範囲であり、個別企業の採択確率ではありません。申請資格が未確定なら算定を停止します。

法人検索の `activityCount` は全種類を合計した法人活動情報件数であり、補助金件数ではありません。活動情報を確認するときは `get_company_activities` を使用します。種類別APIの一部が失敗した場合も取得済み結果を返し、`partial` と `errors` で不足を明示します。

## 開発版のインストールと動作確認

### 回答時の確認指針

検索結果の`searchGuidance`は検索範囲と追加調査の扱い、検索・詳細・適合判定・相談整理の`responseGuidance`は回答時の確認手順です。判定結果ではありません。事業との相性・資格・実行可能性を分け、金額試算前の費用別条件、延期時の資格、採用・研修の事前手続きを必要な場面で確認します。キャッシュの取得後に付けるため、以前に保存した公開情報にも現在の指針を適用します。

同梱の`subsidy-consultation`スキルは、後続の資金相談や申請時期変更にも使う手順です。スキルの利用可否・選択はクライアントに依存し、MCPのツール説明だけで会話全体への適用を保証するものではありません。標準Web検索が使えない場合は、厚労省の調査を行ったことにせず未確認と表示します。

反映にはMCPサーバーのデプロイと、スキルを含むプラグインの更新が必要です。ソース修正だけでは稼働中のChatGPTへ反映されません。新しい検索基盤や制度別の自動計算・資格判定は追加していません。

会話検証用ケースと合格基準は[回答指針の確認ケース](../../test/fixtures/consultation-guidance-scenarios.md)を参照してください。

前提条件:

- このGitHubリポジトリを読み取れること
- GitHubの認証がそのPCのGit環境で完了していること
- Codexがインストールされ、`codex` コマンドを実行できること

マーケットプレイスを追加します。

```powershell
codex plugin marketplace add mkisama94/subsidy_ai_plugin --ref main
```

続いて、補助金AIをインストールします。

```powershell
codex plugin add subsidy-ai@subsidy-ai
```

インストール後は、プラグインのツールを確実に読み込むため、新しいタスクを開始してください。

確認用プロンプト:

> 東京都の省エネ関連で、現在受付中の補助金を3件探してください。候補のうち締切が最も近い制度の詳細も確認してください。

合格条件:

- `search_subsidies` が呼び出される
- 地域固有制度と全国対象制度が検索対象になる
- `get_subsidy_detail` が呼び出される
- Jグランツの制度ID、受付期間、公式詳細URLが表示される
- 検索結果だけで申請資格を断定しない
