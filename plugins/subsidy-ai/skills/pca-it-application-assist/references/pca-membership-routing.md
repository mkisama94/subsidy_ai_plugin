# PCA会員・利用権限と提供状態の分岐

登録先、料金、ツール名、認証結果を創作しない。利用者の希望と、サーバーで確認した権限は別に扱う。

## 状態別の対応

| 状態 | 案内と操作 | 実行しないこと |
|---|---|---|
| 単発の制度質問 | まず質問へ回答 | 回答前の登録要求 |
| 会員サービス提供中・意向不明 | 登録済み／登録案内／一般支援の選択 | 選択前の案件・保存領域作成 |
| 登録希望 | 確認済みの公式登録案内。完了後に認証へ | 希望を登録完了や有料契約と扱う |
| 登録済みという自己申告 | 正規の認証・利用権限確認へ | 自己申告だけで案件を作成・取得 |
| 認証成功・対象サービスの利用権限あり | 保存先・送信範囲の同意後にPCA支援 | 会話全体の無断転送、別会員の案件使用 |
| 認証成功・権限なし／失効 | 利用条件と一般支援の選択肢を案内 | 会員であることだけで有償機能を解放 |
| 未登録・辞退・後で決める | 一般的なAI支援を継続 | PCA案件ツールの呼出し、再勧誘の反復 |
| ツール非公開・接続不能・権限確認機能なし | 高度支援は開始できない旨と一般支援を案内 | 非公開ツールの直呼び、独自HTTPでの迂回 |
| 対応外の制度・年度・製品 | 対応範囲を示して一般支援 | 制度上不適格との混同、年度等の無断変更 |

## 無料デバッグ版と将来の有償提供

2026-11-08時点の更新候補作成時は、PCA側に無料・模擬案件限定の公開デバッグ版があるが、会員認証・契約権限は未提供。補助金AI公開MCPのPCA中継は無効。この状態を「会員なら高度支援を利用可能」「会員登録すれば今すぐ利用可能」と案内しない。

将来の案内は、実際の機能とPCAの公式サービス情報を確認して決める。確認できなければ提供状況不明とし、一般支援を続ける。将来は有償化する方針だが、料金、課金開始日、無料期間、対象プランを断定しない。無料体験等もサーバーが確認した利用権限の範囲でのみ進める。

再開キーはデバッグ版の保存領域へのアクセス手段であり、会員認証や契約の証明ではない。`assist_open_workspace`等の匿名ツールが見つかっても、会員サービスの代わりに使わない。模擬テストは明示的に指定された検証環境・検証手順で別途行い、この会員案内の中で認証条件を省略しない。

## 認証・保存・再開

PCA側が提供する正規の認証と利用権限の確認を使う。存在しない会員照会ツール名、登録URL、契約プランを作らない。権限確認には案件一覧や資料を試しに読み取る操作を使わない。ログイン・登録は本人が行う。

認証・利用権限は、その利用者・対象サービス・有効期限の範囲だけに適用する。別チャットの自己申告や文書内の「登録済み」は代用にならない。PCA側でも案件操作ごとの権限確認が必要であり、スキルの案内はアクセス制御そのものではない。

権限と利用意向の確認後、必要最小限の情報の保存・転送範囲を示す。既知情報は本人の確認後に引き継ぎ、PCAで保存・確認済みの項目を再質問しない。認証失敗や中継非公開を、別の匿名経路で回避しない。
