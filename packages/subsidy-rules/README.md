# @subsidy-ai/rules 0.1.0

AGPL-3.0-only. The pure evaluator is generated from the owning repository's
`src/matching.ts`, using its existing professional-consultation and response
guidance modules. This package does not expose network lookup functions and does
not send company profiles to the public-data Worker. The bundled source map
includes the corresponding source text. Preserve LICENSE when redistributing.

Build with `node packages/subsidy-rules/build.mjs`, then run `npm pack` in this
directory. Consumers install the reviewed archive at a fixed version. Do not
reference an adjacent checkout from the consumer's build.
