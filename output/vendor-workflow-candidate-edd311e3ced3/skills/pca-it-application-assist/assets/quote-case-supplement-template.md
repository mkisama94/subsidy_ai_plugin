|---|---|

| 提案構成 | ［正式製品名・プラン・版・追加製品。数量・期間・価格は対応する見積明細を参照］ |
| 要望への対応 | ［要望に対応する機能・運用、参照する仕様書の該当箇所。追加運用や対象外があれば併記］ |

| 初期設定・移行の範囲 | ［下表、または適用する標準サービス仕様の資料名・版・該当箇所と案件差分］ |
