# 過去申請の再利用と理由付きの質問

## 前回値から変更点を確認する

会社確定後、株主・議決権・兼務等の詳細を聞く前に、受領済み資料と利用者が指定した保存先・案件メールの過去申請を確認する。利用可能な連携で、対象法人・制度・年度に絞って申請書控え、添付資料、前回担当者の回答を探す。保存先が不明なら「前回の申請書控えがあれば、変わった点だけの確認で進められます。保管場所は分かりますか」と一度確認する。資料がない・共有しない場合は、必要な不足確認へ進む。検索だけのために受信箱全体や無関係なフォルダーを読むことはしない。

公的APIの採択・交付履歴と、非公開の申請書本文・株主資料は別物。公開履歴から出資比率等が取得できたことにしない。申請歴と交付決定歴も別で、不採択・取下げの申請控えを再利用できる場合がある。「交付決定なし」だけで過去申請なしと推定しない。今回の案件に存在しない昨年の申請書を前提にしない。

取得できた控えの会社、制度、年度、提出版か下書きか、情報の基準日を確認する。前回値を短く示し、「前回は〔株主・持株比率／議決権／他社支配・役員兼務〕でした。そこから変更はありますか（変更なし／変更あり／確認中）」とまとめて聞く。変更なしの回答がカバーするのは、実際に示した前回値だけ。記載のない議決権比率や兼務を、一般的な「変更なし」から補完しない。株式と議決権を区別する。

変更がある部分、今回から追加された要件、前回資料にない項目だけを補う。出典・基準日・今回の変更確認日を保持し、前年の情報を当年原本に昇格させない。発行期限のある証明書、直近月賃金、当年度の登録、年度固有の認証方式は更新要否を確認する。過去の採択は今回の申請資格の保証ではない。

## 用語・理由・回答を一まとまりにする

質問は「何のことか（初出時）」「何を判断するためか」「今答えること」を短くつなぐ。経理・総務の担当者が制度固有の用語を知っている前提にしない。説明済みの用語を毎回繰り返す必要はない。同じ判断に使う項目は一度にまとめ、未定・分からないも選べるようにする。

2026年11月8日に確認した通常枠・第7次以降の例。年度・枠・申請額・過去交付決定歴が違えば適用要領を確認する。

| 項目 | 短く添える説明・理由 |
|---|---|
| GビズIDプライム | 行政の電子申請で使う法人・事業主向けの本人認証アカウント。申請時のログインに必要なので取得状況を確認する。秘密情報は求めない。 |
| SECURITY ACTION | IPAの制度で、中小企業が情報セキュリティ対策に取り組むことを自ら宣言するもの。通常枠では一つ星または二つ星の宣言が申請要件。宣言だけで補助率が上がる制度とは説明しない。第2回以降は2026年4月開始の管理システムでの宣言が必要なため、既存の宣言記録で方式・IDを補い、未確認の差分だけ聞く。 |
| 株主・兼務 | 大企業の支配や他社との申請重複に関わる条件を確認するため。過去資料で埋まる内容は変更確認だけにする。 |
| 賃上げの計画 | 申請額・過去交付決定歴によって必須要件か任意の加点かが変わる。適用する理由と、必要な基準年度・期間・従業員への表明等を先に説明する。単なる「5％増やす」という回答だけで加点や補助率上昇を確定しない。 |
| 補助率引上げの確認 | 将来の昇給宣言とは別に、指定された過去期間の最低賃金近傍の雇用実績等を確認するため。該当を希望する場合だけ必要期間の資料を案内する。 |
| 直近月の賃金 | 申請時の直近月に地域別最低賃金以上かを確認するため。事業場の所在地・対象月と給与内訳・所定労働時間の根拠が必要。過年度の年次資料とは別用途なので、初回の資料案内から分けて予告する。 |
| 売上・利益・時間の計画 | 労働生産性向上の実現可能な計画を作るため。賃上げ率と労働生産性の伸び率は別の指標。 |

賃上げ加点を選ぶ前に、任意か必須か、達成・報告等の約束が何かを説明する。通常枠150万円未満・過去交付決定なしのケースで、加点を希望しない人に詳細な賃上げ計画を一律に作らせない。必要な基本入力は別に整理する。

## 計画はまとまりで確認し、矛盾は早めに示す

計画資料がなければ、既存の決算値と既知の希望から空欄付きの3年表を先に示す。「変えたい項目だけ」「未定のまま」でも回答できるようにし、売上→利益→人数→役員報酬を年度ごとに反復質問しない。仮置きと本人が決めた目標を明示する。

売上・総労働時間を据え置き、賃上げ分だけ営業利益を下げるなら、生産性の式で利益と人件費が相殺する点をその時点で示す。別業務へ振り向ける時間を総労働時間削減に数えず、申請要件に合わせて架空の成長・削減を作らない。追加の見込みなしと回答されたら同趣旨の質問を続けず、計画を未充足として他の独立した準備へ進む。
